# Калькулятор на Go

Консольный калькулятор: читает из stdin два числа и знак операции, печатает
результат. Первый проект на Go — знакомство с языком, `switch` и обработкой
некорректного ввода.

![Go](https://img.shields.io/badge/Go-1.x-00ADD8?logo=go&logoColor=white)

## Что умеет

Операции `+`, `-`, `*`, `/`, `%`. Деление и остаток от деления на ноль
перехватываются и не роняют программу, неизвестная операция сообщается явно.

## Запуск

```bash
go run main.go
```

Ввод — три значения через пробел или перенос строки:

```
12 4 /
3
```

Сборка бинарника:

```bash
go build -o calculator main.go
./calculator
```

## Ансестологическая карта

Отдельный расчёт по дате рождения: рабочие числа, число родового пути (ЧРП)
и карта 3×3 (квадрат Пифагора). Учтены даты 1800–1899, 1900–1999, с 2000 года
и с 2020 года.

```bash
go run ./cmd/ancestral 01.12.1983 "Иванова Лариса Петровна"
go test ./ancestral/
```

Финансовый канал пока не реализован: правила расчёта нужно взять из курса.
