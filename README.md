# Калькулятор на Go

Консольный калькулятор: читает из stdin два числа и знак операции, печатает
результат. Первый проект на Go — знакомство с языком, `switch` и обработкой
некорректного ввода.

![Go](https://img.shields.io/badge/Go-1.x-00ADD8?logo=go&logoColor=white)

## Что умеет

Операции `+`, `-`, `*`, `/`, `%`. Деление и остаток от деления на ноль
перехватываются и не роняют программу, неизвестная операция сообщается явно.

## Запуск

```bash
go run main.go
```

Ввод — три значения через пробел или перенос строки:

```
12 4 /
3
```

Сборка бинарника:

```bash
go build -o calculator main.go
./calculator
```

## Ансестологическая карта

Отдельный расчёт по дате рождения: рабочие числа, число родового пути (ЧРП)
и карта 3×3 (квадрат Пифагора). Учтены даты 1800–1899, 1900–1999, с 2000 года
и с 2020 года.

```bash
go run ./cmd/ancestral 01.12.1983 "Иванова Лариса Петровна"
go test ./ancestral/
```

Тот же расчёт есть в виде одного файла `ancestral.html`: его можно сохранить
на телефон и открывать без интернета.

## Финансовый канал

По карте считается родовой финансовый канал — средний столбец «Деньги»
(цифры 4, 5, 6: 4 — крыша, 5 — стены, 6 — фундамент). Программа определяет
модель канала (устойчивый/неустойчивый, идеальный/слабый/перегруженный),
степень влияния родовых программ, точки входа (через что легче приходят
деньги) и чего не хватает. Правила взяты из модуля 3, урок «Родовой
финансовый канал». Расчёт есть и в Go (`ancestral.Finance`), и в
`ancestral.html`; оба совпали на всех датах 1800–2099 и на примере из курса
(15.08.2001).

ФИО в расчётах не используется: и карта, и финансовый канал считаются только
по дате рождения. Имя — лишь подпись доверителя.
